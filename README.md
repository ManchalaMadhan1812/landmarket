# 🏡 LandMarket

A full-stack real estate marketplace built with **Django**, **React**, and **MongoDB Atlas**. Users can browse, list, and manage properties through a modern and responsive web application.

## ✨ Features

- 🔐 User Authentication
- 🏠 Property Listings
- 🔍 Advanced Search & Filters
- 💬 Real-time Chat
- 💳 Razorpay Payment Integration
- 📱 Responsive UI
- 👤 User Dashboard

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Django, Django REST Framework
- **Database:** MongoDB Atlas
- **Payments:** Razorpay

## 🚀 Getting Started

```bash
git clone https://github.com/ManchalaMadhan1812/landmarket.git
cd landmarket
```

Install dependencies, configure the environment variables, and start the frontend and backend servers.
